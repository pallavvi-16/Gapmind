  • Practice with a timer and eliminate options before calculating everything.

Coding

Company-style coding practice focused on patterns, complexity and clean implementation.

Not completed

What to study

  • Arrays, strings, hashing, two pointers and sliding window.
  • Stacks, queues, linked lists, trees and graphs.
  • Always state time and space complexity before finalizing a solution.
  • Practice edge cases: empty input, duplicates, one element and large input.

Practice set

Two Sum · Reverse Array · Valid Parentheses · Binary Search · Maximum Subarray · BFS/DFS.

CS Fundamentals

Revise the core technical subjects that frequently appear in placement interviews.

Not completed

What to study

  • DBMS: keys, normalization, SQL, joins and transactions.
  • Operating Systems: processes, threads, scheduling, deadlocks and memory.
  • OOP: encapsulation, inheritance, polymorphism and abstraction.
  • Computer networks: OSI/TCP-IP, HTTP, DNS and common protocols.
